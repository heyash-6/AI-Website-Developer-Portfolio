# Project Brief — 3D Personal Portfolio Website

## Goal
Build a modern, single-page (or smooth-scroll multi-section) personal portfolio website for a freelance AI Website Developer. The site should feel premium, futuristic, and interactive — showcasing skills and projects while leaving a strong first impression through 3D visuals and motion.

## Target Audience
- Potential freelance clients (small businesses, startups) looking to hire an AI-powered web developer
- Visitors arriving from Fiverr, LinkedIn, GitHub, or direct referral links

## Core Requirements
1. **3D floating object** in the Hero section (abstract shape/sphere), subtly rotating and reacting to mouse movement
2. **Grainy noise texture effect** that becomes visible/animated on hover over key elements (buttons, cards, images)
3. **Scroll-triggered animations** — sections and elements fade/slide/reveal smoothly as the user scrolls down
4. **Dark futuristic theme** — black background with neon accent colors
5. Fully responsive (desktop, tablet, mobile)
6. Fast load time — 3D and animation effects should be optimized, not laggy

## Sections (in order)
1. Hero / Intro
2. About Me
3. Skills / Services
4. Projects / Portfolio
5. Testimonials
6. Contact Form
7. Footer with LinkedIn + GitHub links

## Tone
Confident, modern, minimal-text, visual-first. Let the design and motion do the talking — avoid long paragraphs.

## Recommended Tech Stack
- React (or Next.js) as the base framework
- Three.js via React Three Fiber — for the 3D floating object
- Framer Motion or GSAP (with ScrollTrigger) — for scroll-based animations
- CSS/SVG noise texture or a WebGL grain shader — for the hover grain effect
- Fully self-contained, deployable as a static site

## Deliverable
A working, responsive website matching the design spec and content structure in the accompanying `DESIGN_SPEC.md` and `CONTENT.md` files.
